## Tiny stack VM

A compact Node.js runner for the `tiny-stack-vm-01` bytecode challenge. It reads
instances from `/input` and writes each result under `/output`.

Run locally with:

```sh
MAKEFUN_INPUT_DIR=practice/input MAKEFUN_OUTPUT_DIR=out node main.ts
```
